Sudoku Solver Web App-
A web-based Sudoku solver using advanced AI techniques:

1.Constraint Satisfaction Problem (CSP) formulation.
2.AC-3 algorithm for constraint propagation
3.Backtracking search for solution completion
4.Flask web interface for user interaction



 ->Getting Started
Requirements:
Python 3.7+
Flask

 ->Installation:
pip install flask

Run the App:
python app.py

 ->Technologies Used:
Python
Flask
AC-3 (Arc Consistency Algorithm)
Backtracking Search
